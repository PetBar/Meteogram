# Meteogram (instalovatelná webová aplikace)

Obsah složky nahrajte na HTTPS hosting. Bez HTTPS Chrome instalaci nenabídne (ani z otevřeného souboru z disku):
- nejrychlejší: https://app.netlify.com/drop (přetáhněte celou složku, zdarma, odkaz hned),
- nebo GitHub Pages: https://pages.github.com/

Na mobilu otevřete odkaz v Chrome. Nabídne se "Nainstalovat aplikaci" (nebo tlačítko "Instalovat" přímo v aplikaci).
Odkaz můžete poslat dalším lidem.

Zdroje dat a proxy pro ČHMÚ meteogram: viz ozubené kolečko v aplikaci a worker.js (Cloudflare Worker).
